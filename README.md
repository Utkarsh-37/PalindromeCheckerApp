Use Cases

UC1 – Application Entry Displays the welcome message, version, and initializes the application flow. Introduces the role of main() as the entry point.

UC2 – Hardcoded Palindrome Check Validates a fixed string using basic character comparison. Simple and perfect to warm up with conditional logic.

UC3 – Reverse String Approach Reverses the string manually using a loop and compares it to the original. Demonstrates string iteration and immutability.

UC4 – Character Array (Two‑Pointer Technique) Converts the string into a char array and checks from both ends. Efficient and memory‑friendly; introduces pointer‑style logic.

UC5 – Stack‑Based Validation Uses a Stack to reverse the string implicitly via LIFO behavior. Reinforces stack fundamentals and reversal logic.

UC6 – Queue + Stack Hybrid Stores characters in both a Queue (FIFO) and a Stack (LIFO), then compares outputs. Great for understanding the contrast between these two structures.

UC7 – Deque‑Based Palindrome Checker Uses a Deque to pop from front and rear. Optimized bidirectional comparison without extra structures.

UC8 – LinkedList‑Based Approach Stores characters in a LinkedList, then removes from both ends. Highlights linked list operations and symmetric character matching.

UC9 – Recursive Palindrome Checker Compares characters recursively from outer to inner positions. Teaches recursion, call stack behavior, and base conditions.

UC10 – Case‑Insensitive & Space‑Ignored Palindrome Preprocesses the string by: Removing spaces Removing non‑alphanumeric characters Converting to lowercase Performs normalized palindrome validation.

UC11 – Object‑Oriented Palindrome Service Encapsulates logic inside a PalindromeService class. Introduces OOP concepts like encapsulation, SRP, and clean API design.

UC12 – Strategy Pattern (Dynamic Algorithm Selection) Defines a PalindromeStrategy interface and multiple implementations. Allows runtime selection of algorithms → demonstrates polymorphism and Strategy Design Pattern.

UC13 – Performance Benchmarking Measures execution time of different algorithms using System.nanoTime(). Focuses on benchmarking, performance awareness, and practical comparison.
